MISE EN LIGNE SUR GITHUB PAGES (SITE STATIQUE)
1. Sauvegarder le dépôt actuel ou sa branche principale.
2. Transférer le CONTENU du dossier synaptech-site-main (pas son dossier parent)
   à la racine du dépôt GitHub Pages qui dessert synaptech.tn.
3. Garder CNAME et les sous-dossiers mawjoud/ et rivo/.
4. Vérifier sur smartphone, la version anglaise et les liens produits.
5. Vérifier la réception de hello@synaptech.tn, y compris OVH/Zimbra
   si la boîte n'est pas hébergée dans Gmail. Les MX peuvent être distincts
   du service Resend utilisé pour envoyer les e-mails.

FORMULAIRES : ÉTAT RÉEL
Le formulaire n'envoie pas automatiquement une demande vers un serveur.
Il prépare une demande détaillée dans le logiciel e-mail du visiteur ou
ouvre WhatsApp avec les informations préremplies. Le visiteur doit ensuite
CONFIRMER l'envoi dans son application. Aucun formulaire ne prétend
avoir transmis des informations qu'il n'a pas envoyées.

Pour un dépôt de demande sans app e-mail ni WhatsApp, un vrai backend est
nécessaire (service de formulaire conforme à la confidentialité, ou
Cloudflare Worker/Netlify Functions + serveur e-mail sécurisé). Ne jamais
mettre de clef API Resend dans un fichier HTML/JS visible publiquement.
Avant publication comme service de prospection opérationnel : tester le
parcours contact de bout en bout et valider la boîte de réception.
